# Raya V1 训练方案（定稿 · 资源申请版）

> 状态：已定稿（2026-09-23）。取代 `datasets-v1.md` 中的训练与配比部分。
> V1 范围：**文本 + 图片 + 视频** 的结构化决策（音频 V2 再做）。
> 产品目标：生产可用的多模态 System-1 决策模型——单次前向、结构化可验证输出、校准置信度、共享前缀扇出。

## 0. 验收指标（里程碑门禁，不过门不进下一阶段）

| 指标 | 目标 | 说明 |
|---|---|---|
| 决策准确率 | ≥ 基座 zero-shot + 15pt（各 held-out 集） | 对标 Qwen2.5-VL-3B 直读 logits 基线 |
| ECE（校准误差） | ≤ 0.08 | 对标 Laya 公开值 0.081 |
| 延迟 | 单决策 p50 < 50ms；扇出边际 < 10ms | H20 上实测，含共享前缀 |
| 拒答准确率 | 弃权类样本上 ≥ 85% | 生产必备能力 |
| 结构合规率 | 100% | 输出恒在候选空间内（掩码保证，回归测试守住） |

评测集（held-out，**一条不进训练**）：SEED-Bench、Video-MME、MVP（防捷径）、POPE、MMLU、Banking77 test、ChaosNLI + **自建决策场景集**（含拒答类）+ 上线前真实日志回放集。

## 1. 基座与推理形态

- **基座**：Qwen2.5-VL-3B-Instruct（dense；原生支持图片/视频抽帧；4bit ~2GB 端侧可跑）
- **推理协议**：state（多模态前置）→ 问题 → 候选列表（服务端分配标签 token 并建映射）→ 单次前向 → 末位 logits 掩码投影 → 局部 softmax → choice / noul / score 三原语
- **扇出**：共享 state KV cache，N 个问题后缀并发打分
- **约束在模型外**：选项空间由服务端掩码强制，模型不参与合规性

## 2. 训练流水线（四步，顺序执行）

### Step 0 — 教师蒸馏数据生产（补软标签缺口）
- 教师：Qwen3-Omni-30B-A3B Thinker（本地）或 GPT-4o 级 API
- 对象：**视频训练集 + 决策场景集**（这两类无人类软标签）
- 产出：每题的候选概率分布（软标签），供 SFT 软目标 + RLCD 分布奖励使用
- 成本：决策=单次前向，~100K 次前向，H800 数小时

### Step 1 — SFT 格式对齐（LoRA，配方迭代用）
- **损失函数：option-local listwise 交叉熵**——只在本次候选的标签 token 上归一化做 CE，全词表其余位置不参与（⚠️ 不是标准全词表 LM loss；训练读出方式必须与推理一致）
- 冻结视觉编码器；LoRA 作用于 projector + LLM
- 用途：快速迭代数据配比/模板/标签风格配方
- 资源：1×H800，~2-3h/轮

### Step 2 — 全量微调（配方定稿后，交付版）
- 解冻视觉塔顶层 + LLM 全参数，沿用 option-local 损失
- 用途：拉能力上限（尤其视频时序推理），最终交付模型走此版
- 资源：2×H800（ZeRO），~8-12h/轮

### Step 3 — RLCD 校准（GRPO）
- 奖励：严格恰当评分规则（log score / Brier）对照硬标签或**软分布**（VQA v2 10 人分布 / ChaosNLI 100 人分布 / Step 0 教师分布）
- GRPO：同题组内采样（对掩码后 softmax 加温度采样），组内归一化，无 value model
- 注意：全量版 RLCD 需策略+参考双模型 ≈ 96GB > 单卡 80G，**必须 2 卡**
- 资源：2×H800，~4-8h/轮

## 3. 训练集范围（定稿）

### 3.1 理解题基底（学术集，保证理解能力）

| 模态 | 数据集 | 规模(取用) | 原语 |
|---|---|---|---|
| 文本 | RACE / MNLI / CommonsenseQA | 40K | choice |
| 文本 | BoolQ / SST-2 / SST-5 | 15K | noul / score |
| 文本 | Banking77 / CLINC150 / AG News | 15K | choice(高基数) |
| 图片 | **VQA v2 train**（含 10 人软标签） | 45K | choice/noul + 软标签 ⭐ |
| 图片 | GQA train 子集 | 25K | choice/noul |
| 图片 | KonIQ-10k / AVA 子集 | 10K | score |
| 视频 | LLaVA-Video-178K MC（合成，配比 ≤60%） | 35K | choice |
| 视频 | NExT-QA train / STAR train / TGIF-QA | 30K | choice |

### 3.2 决策场景题（生产题型，学术集没有）

| 场景 | 来源 | 规模 |
|---|---|---|
| 内容审核 | ToxicChat / Aegis | 10K |
| Agent 动作选择 | Mind2Web / AndroidWorld（截图→候选动作） | 10K |
| 意图路由 | Banking77 / CLINC150（计入 3.1） | — |

### 3.3 拒答/弃权类 ⭐（生产必備，~8% 占比）
CLINC150 OOS 样本 + 自构造三类：选项全不对 / 输入模态缺失 / 证据不足 → 正确答案是「无法判断」。

### 3.4 中文决策数据（~10-15%）
教师模型蒸馏 + 高质量翻译改造，覆盖三模态。

### 3.5 软标签资产（RLCD 燃料）
- VQA v2：10 人标注分布（图）⭐
- ChaosNLI：100 人标注分布（文，4.6K）⭐
- Step 0 教师分布：视频 + 场景题

### 3.6 配比与总量

**SFT ~200K**：文本 25% / 图片 40% / 视频 35%；其中场景题+拒答类合计 ~15%，中文 ~10-15%（跨模态分布）。
**RLCD ~25-50K**：人工标注 MC 为主 + 全部软标签子集。

### 3.7 质量纪律
1. 干扰项用难负例（同大类/embedding 近邻），禁随机负例
2. 合成:人工 ≈ 6:4，人工集为质量锚
3. 选项顺序渲染时洗牌，正确答案位置均匀
4. 标签风格渲染时随机轮换（A/B/C、1/2/3、yes/no、自定义枚举词）
5. 训练/评测严格分离，adapter 记录每样本血缘（source/split/license）

### 3.8 许可证红线
ScienceQA = CC BY-NC-SA（非商用）、A-OKVQA 许可证不明 → 研究可用；**开源发布权重前必须替换或确权**。

## 4.5 开发-训练工作流（已定）

**本地冒烟全绿 → 同步服务器 → 正式训练，Claude SSH 上机监控。**

1. **本地开发**（本机 + PRO 5000-72G）：代码、adapter、渲染器、训练脚本开发；用 ~1K 样本子集跑通完整训练 loop（单卡、小 batch、几十步），验证 loss 下降、checkpoint 读写、日志落盘
2. **硬件无关性纪律**：训练脚本单卡/多卡同一套代码（torchrun + ZeRO 配置化），本地单卡冒烟 = 服务器多卡逻辑的降级路径，不允许「服务器特供」代码路径
3. **同步**：git 为主（数据集不进门，走下载脚本 + 血缘清单），服务器环境用 conda env 锁定
4. **训练监控**：loguru 结构化日志落盘（loss/ECE/lr/吞吐/GPU 显存，按 step 滚动），Claude 通过 SSH 观察进度、日志、nvidia-smi，异常按日志定位不靠猜
5. **服务器冒烟**：正式训练前先在服务器上跑同一 1K 冒烟（排除环境差异），绿了再开正式 run
6. **checkpoint 协议**：按 step + 按指标双轨保存，每轮训练结束跑 held-out 评测门禁，过门才进入下一阶段

## 5. 里程碑

- [ ] **M1 数据层**（~1 周）：统一 schema + 下载脚本 + adapter（RACE/VQA v2/KonIQ/NExT-QA/LLaVA-Video 先行）+ 血缘记录
- [ ] **M2 渲染器 + 推理 harness**（~1 周）：模板/标签随机化/洗牌 + 掩码投影 + 共享前缀扇出 + 基线评测（基座 zero-shot 数值）
- [ ] **M3 Step 0+1**（~1.5 周）：教师蒸馏 + SFT-LoRA 配方迭代 → temperature scaling 基线，出首份 accuracy/ECE/延迟报告
- [ ] **M4 Step 2+3**（~1.5 周）：全量 FT + RLCD，过全部门禁指标
- [ ] **M5 评测报告 + 场景验收**（~1 周）：held-out 全量报告，对标 Jev/Laya 公开数据，真实日志回放验收

## 6. 风险登记

| 风险 | 缓解 |
|---|---|
| MVBench 捷径问题污染评测结论 | 评测主力用 Video-MME + MVP |
| 合成数据偏置 | 6:4 配比 + 人工锚 + RLCD 阶段只用人工/软标签 |
| 候选项注意力竞争（多模态 token 长会放大） | 模板锁死 state 前置候选后置；M2 阶段实测验证 |

| 3B 视频能力天花板 | Step 2 解冻视觉塔；若仍不达标，升级路径=Qwen2.5-VL-7B（资源另议） |
