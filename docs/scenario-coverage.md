# Raya 场景覆盖矩阵（数据集设计第一公民）

> 原则：数据集不是凑出来的，是**按场景设计出来的**。
> 每个格子 = 场景 × 决策类型，标注数据来源与目标量；无现成数据的格子用教师合成（MiniMax-M3 生成 + 人工抽检）。
> 泛化验收：leave-one-scenario-out 测试（整域不训，测零样本迁移）。

## 二、泛化设计（比单域数据量更重要的五件事）

1. **每域下限**：任何场景域 ≥8K 样本——宁可砍域不可瘸腿（瘸腿域 = 负优化，模型学不会还污染校准）；
2. **场景标签不入模型**：场景分类法只用于数据配比和评测切片，**不作为输入特征**——防止模型依赖场景先验而损失跨域泛化；
3. **标签风格/选项数量/模板全域随机**（渲染层）：模型学「读当前 prompt 的候选」这一可迁移技能；
4. **leave-one-scenario-out 验收**：每个域轮流整体移出训练集，测该域零样本准确率 + ECE——这是「泛化」的硬指标，不是看训练域内分数；
5. **软标签跨域复用**：VQA v2（10人）/ChaosNLI（100人）/M3 教师分布（视频+场景域），校准训练在所有域上共享。

## 三、评测集对应关系（held-out）

SEED-Bench / Video-MME / MVP / POPE / MMLU / Banking77 / ChaosNLI（通用）+ 每场景域自留 1-2K 测试切片（S1-S7 从源数据的官方 test split 切，S2 合成域人工定稿）+ 上线前真实日志回放集。
